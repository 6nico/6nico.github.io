Crash Log Analyzer

Windows app that explains crash logs, splits facts from possible causes, and suggests one next step. Uses the Gemini API with structured outputs and removes personal info before sending.

The problem

When a program or the whole PC crashes, Windows writes down what happened, but in codes almost nobody can read.

What I built

  • Lists every crash from the last 7 days and groups repeats from the same incident
  • Removes personal info from the log before anything leaves the PC
  • Uses the Gemini API (or Claude / OpenAI) with structured outputs to separate facts from possible causes
  • Ends with one clear next step to try first

What I learned

Structured outputs make AI answers predictable enough to put in a real UI: every result has the same shape, so the app can trust it.
