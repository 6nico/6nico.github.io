The problem

Activity Monitor shows everything but explains nothing. Most people can't tell which background process is slowing their Mac down, or whether closing it helped.

What I built

  • One view of running apps, CPU, memory and background processes
  • Simple controls to quit or pause what you don't need
  • Before-and-after performance checks so you can see the difference
  • A product spec written before the first line of code
